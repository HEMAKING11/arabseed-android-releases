# Arabseed Downloader for Android

A compact Android app for downloading movies and series episodes from Arabseed links.

## Features

- Choose a download quality for each episode.
- Review the selected file count and known download size before adding files.
- Download inside the app, with pause and resume controls.
- Adjust concurrent downloads and connections per file.
- Open arabseed.com from Home.

## Requirements

Android 8.0 or later.

## Downloads and updates

This repository is reserved for Android APK releases, checksums and update metadata. Application source code and signing keys are not included.

APK files and release notes are available in the repository’s Releases section.
